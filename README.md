# 重生世界杯 V5.2

手机优先的 2026 世界杯重生积分模拟器。

## V5.2 规则

- 初始积分：100。
- 每注最低 5 积分，下注档位以 5 的倍数计算。
- 同场支持多选；再次点击已选项即可取消。
- 同场每多选一个结果就多 1 注，总投入 = 选项数 × 每注积分。
- “全部投入”会按当前全部已选注数，自动选择不超过余额的最大 5 的倍数作为每注积分；无法投入的零钱保留在账户中。
- 当结算后余额低于 5 积分时，本轮重生失败，需要重新开始。
- 当天可以完全不选择，直接“跳过今天”。

## 历史固定奖金

`sporttery-fixed.js` 是前端读取的固定奖金数据文件。

仓库内包含：

- `scripts/fetch_sporttery_fixed.py`：批量抓取 104 场历史固定奖金及半场赛果。
- `.github/workflows/import-fixed-bonus.yml`：上传到 `main` 后会自动尝试生成完整 `sporttery-fixed.js`，也可以在 Actions 页面手动运行。
- `sporttery-fixed-report.json`：任务运行后生成的数据完整性报告。

采集器要求 **104/104** 场的胜平负、让球、31 项比分、总进球、半全场和半场赛果全部齐全才会提交生成文件；缺任何一场都会报错，不会用模拟赔率冒充真实历史数据。

GitHub Pages 继续使用 `main / (root)` 即可。
